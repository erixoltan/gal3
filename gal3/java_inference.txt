comment `
The java backend, built for the five-languages article: it must compile the
five contract programs (hello, fizzbuzz, bank, receipt, checkout) and fail
loudly beyond them, per the c_inference.txt philosophy.

3.2 promotion in progress (docs/java_selfhost_design.md): this backend is
growing toward the full 1:1 mirror of python_inference.txt so the compiler
itself can run on the jvm. fail-loudly stays the rule for anything not yet
ported.

java is the managed-vm point on the spectrum: everything lives in a class,
so the interesting mappings are module -> the public class holding
public static void main, gal class -> a package-private sibling class in
the same file (java only restricts PUBLIC classes to one per file),
dict -> HashMap with the value type read from the first sibling d=
assignment, list -> List.of, say and append -> string concatenation with
+ (java converts any operand adjacent to a string), and a string operand
in a numeric operation -> an inline Integer.parseInt or Double.parseDouble,
which unlike go needs no helper because it is a plain expression.

imports collect in class-level registries on Element, exactly as the go
backend does, and the Program generator emits the import lines first.
helper functions are rare (only readline needs one, a shared Scanner);
they collect into a package-private Gal class appended after everything
else, so any class in the file can call Gal.readline().

the public class must live in a file named after it, so the driver of the
oracle names the output file after the module.
`;

class Java_Compiler is Fallback_Compiler
{
    constructor
    {
        my Generator = (new Java_Generator [self]);
    }
    method void Print_Errors
    {
        object E;
        for each E in [my Elements]
        {
            if (not ([E.Error] is null))
            {
                say [line]
                    [class name [E.Classification]]
                    ': '
                    (substring (E.Get_Input) 0 80);
                say 'ERROR: ' [E.Error];
            }
        }
    }
    method number Infer_Code
    {
        verbosity;
        [my Generator Elements] = [my Elements];
        number Status = ([my Generator].Infer_Gal);
        if (not Status)
        {
            i Print_Errors;
            say 'Error in Java inference, inferring gal';
            return 0;
        }
        Status = ([my Generator].Infer_Fallback);
        if (not Status)
        {
            i Print_Errors;
            say 'Error in Java inference, inferring fallback';
            return 0;
        }
        Status = ([my Generator].Infer_Java);
        if (not Status)
        {
            comment `a subset backend fails loudly: a generator error on any
            element must fail the compile, not leak None into the output`;
            i Print_Errors;
            say 'Error in Java inference, inferring java';
            return 0;
        }
        object Top = (llast [my Elements]);
        try
        {
            if ([Top.Java] is null)
            {
                Top.Infer_Java;
            }
        }
        catch Error
        {
            say 'Error in Java inference: ' Error;
            return 0;
        }
        my Java = [Top.Java];
        return 1;
    }
}
